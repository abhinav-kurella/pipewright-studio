# Pipewright Studio website

Single-file static site for Pipewright Studio, a marketing systems studio for B2B teams.

## View it
Open `index.html` in any browser. It works offline (fonts fall back to system fonts without internet).

## Pitch mode
Click **Pitch mode** in the header to present the site one section per screen.
- Next: → / Space / swipe left
- Back: ← / swipe right
- Exit: Esc

## Before going live
- Buy a domain and update the email address in the Contact section.
- Deploy: GitHub Pages (Settings → Pages → Deploy from a branch → `main` / `(root)`). On a free plan the repo must be public.
